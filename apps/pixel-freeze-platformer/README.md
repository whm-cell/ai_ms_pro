# Pixel Freeze Platformer MVP

REQDOC-003 / WS-04 repo-native playable MVP.

Open `index.html` through a local static server, or run:

```bash
python3 scripts/pixel_freeze_platformer_smoke.py
```

The smoke path validates content metadata, movement, jump, attack, level clear, campaign completion, locale switching, and reset. This app validates the product loop from `prd_game.md` without claiming Godot engine, GUT, export, final art, final audio, or mobile release readiness.
