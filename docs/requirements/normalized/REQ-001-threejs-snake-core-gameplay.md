# 标准化需求：Three.js 贪吃蛇核心玩法

更新时间：2026-04-16
需求编号：REQ-001
来源文档：REQDOC-001
需求标题：提供可玩的 Three.js 贪吃蛇核心玩法
状态：已完成

## 背景

- 需要用一个真实可玩的场景验证当前 harness 和 requirements 体系，而不是仅停留在文档流程层面。
- 贪吃蛇是足够小但又具备明确交互、状态管理和渲染需求的典型场景。

## 目标

- 提供一个可运行的 Three.js 贪吃蛇游戏
- 玩家可以控制蛇移动、吃到食物、增长长度并在失败后重新开始

## 范围

### 包含

- 网格化地图上的蛇移动
- 食物随机生成与得分增长
- 撞墙或撞到自身后的 game over 判定
- 重新开始游戏的入口

### 不包含

- 联网对战
- 账号系统、存档、排行榜
- 复杂关卡系统或多模式玩法

## 验收条件

- 游戏可以实际运行，且蛇能按固定节奏移动
- 玩家能通过键盘控制方向
- 吃到食物时蛇长度增加且分数更新
- 发生碰撞时游戏结束，并能重新开始

## 依赖与前置条件

- 需要一个 Three.js 渲染场景
- 需要最小可用的页面承载入口
- 需要 requirements 与 handoff/status 文档同步记录该场景

## 风险与待澄清项

- 当前仓库没有前端工程脚手架，需要决定使用零构建静态方案还是引入工具链
- 若网格、相机和渲染比例处理不当，游戏可能虽能运行但体验较差
