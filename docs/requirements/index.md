# 需求文档入口索引

更新时间：2026-04-15
当前状态：初始化

## 目的

本目录用于管理项目的需求来源、需求标准化结果、工作流拆解和需求追踪关系。

它回答四个问题：

- 原始需求文档有哪些
- 每份需求文档标准化后是什么
- 这些需求被拆成了哪些可执行工作流
- 当前开发阶段正在响应哪些需求

## 使用规则

- `source/` 只保存原始需求文档或原始需求转录稿
- `normalized/` 将原始需求统一整理成一致结构
- `workstreams/` 将多个需求映射成可开发的业务工作流
- `traceability-matrix.md` 负责串联 `需求 -> 工作流 -> 阶段 -> 实现/测试`
