# Handoff 模板

更新时间：YYYY-MM-DD
阶段：stage-XX
任务：task-name
状态：进行中 | 待接力 | 已完成

## 本任务目标

- 说明当前任务要完成什么

## 已完成内容

- 列出已经完成的实现、检查和验证

## 修改文件

- [示例文件](/absolute/path/to/file)

## 关键实现决策

- 记录会影响后续执行的关键判断

## 已验证有效的路线

- 记录已经验证可行、后续可继续沿用的方案

## 已验证无效的路线

- 记录已经尝试但应避免重复投入的方案

## 尚未尝试但建议的路线

- 记录下一位 Agent 值得优先评估的候选方案

## 当前未完成项

- 列出仍待完成的内容

## 已知风险与注意事项

- 记录坑点、约束或风险

## 下一位 Agent 的第一步动作

- 用一句话写清楚下一步从哪里开始

## 建议同步更新

- 必要时更新 `status`
- 阶段收尾时更新 `changelog`
- 检查 [AI 文档入口索引](/Volumes/usd/codes/go_projects/ai_ms_pro/docs/ai/index.md)
